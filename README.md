# Paradise Nursery

## Project Name

Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is an online plant shopping application that allows
users to browse different types of plants and add them to a shopping cart.

## Features

- User-friendly landing page
- Paradise Nursery company information
- Plant listing with images, names, prices, and categories
- Add plants to the shopping cart
- Dynamic cart item count
- Increase and decrease plant quantities
- Remove plants from the cart
- Calculate individual and total cart costs
- Checkout option
- Continue shopping option
- Navigation between Home, Plants, About Us, and Cart pages

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- React Router DOM
- JavaScript
- CSS
- HTML
